# Ewspurp Frontend

This is the frontend for Ewspurp, built with Vite, React, and Tailwind CSS.

## Stack
- Vite (latest)
- React (latest)
- Tailwind CSS (latest)

## Setup

```sh
npm install
npm run dev
```

## Project Structure
- `src/components/` — React components
- `src/context/` — React context (global state)
- `src/utils/` — Utility functions

## API
- Connects to the Ewspurp backend via REST API (see backend for details).
